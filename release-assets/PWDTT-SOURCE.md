# PWDTT Client — исходный код (GPL-3.0)

В ранних релизах WDTT файлы `pwdtt-client-linux-amd64` и `pwdtt-client-windows-amd64.exe`
содержали **модифицированную версию** десктопного клиента **PWDTT**.

|---|---|

| **Исходники этой версии** | https://github.com/ildarmaga/pwdtt-client |
| **Лицензия** | [GNU GPL v3.0](https://www.gnu.org/licenses/gpl-3.0.html) |

По условиям GPL-3.0 §6 вы можете получить исходный код, соответствующий
распространяемым бинарникам, из репозитория **ildarmaga/pwdtt-client** (ветка `main`, теги `v*`).

Версию исторического файла можно посмотреть в описании соответствующего релиза или в файле `release-assets/pwdtt-client-version` на его теге.
